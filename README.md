# Vanessa's Christmas List

The webpage is in `index.html`. It is ready for GitHub Pages.

## Turn on shared claims

1. Create a new Google Sheet.
2. Select **Extensions → Apps Script**.
3. Replace the starter script with the contents of `Code.gs`, then save.
4. Select **Deploy → New deployment → Web app**.
5. Set **Who has access** to **Anyone**, then deploy and authorize it with your Google account.
6. Copy the web-app URL and send it to Vanessa's assistant. The assistant will add it to `index.html`.

The Sheet only stores an item ID, the claimant's first name, and the time claimed.
